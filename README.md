# 台灣電視遊樂器史料庫｜電視遊樂雜誌專藏

站台：**https://wicanr2.github.io/tv-game-magazine-history-site/**

1987 至 1996 年台灣電視遊樂器的引進、代理、拷貝與灰色市場、媒體及出版產業史。
史料出自《電視遊樂快訊》《電視遊樂情報》《電視遊樂報導》及其特輯共 23 冊、2,532 個掃描頁。

## 內容

- **史書**七章：序章解三個刊名的沿革，五章依年代推進（1987 創刊／1988–89 拷貝的全盛／
  1990–93 代理權進場／1994–95 本土製作與台灣主機／1996 授權中文版與改制），
  終章列缺口與材料界線
- **編年史**：1987–1996 逐則條目，每則附內容、來源與備註
- **條目**：人物、公司與組織、刊物
- **館藏書目與數位化**：23 冊書目、數位化管線與史料紀律
- **原刊全文**：23 冊逐頁 OCR 文字，供檢索定位

## 引用方式

每則硬事實都附掃描頁碼與來源性質。掃描頁序（`0001.jpeg` 即掃描 p.1）與雜誌自己印的頁碼
是兩套編號，站內分別標示。雜誌報導、廣告文案、讀者投書、編輯評論、版權頁、封面的
可信度不同，引用時一律標明來源性質——廣告主自述的宣稱不作查證過的事實使用。

OCR 文字只用來定位，不能當引文：RapidOCR 對 1980 年代的掃描品質與直排會混入誤字。
站內史書與條目引用的每則硬事實，都另以掃描原圖核對過。

## 掃描原件

原始掃描件不在本 repo。原件取自「小熊们的云端存储」的公開分享，
著作權屬各刊物的權利人。本站只發布研究整理的文字產物與逐頁 OCR 結果，
引用以頁碼為準。

## 產生方式

本 repo 的 HTML 由研究工作區的 markdown 產生（`scripts/build_site.py`，
在鎖版容器內執行），純靜態，不經 Jekyll。
